# Student Finance

Бэкенд для персонального трекера расходов. Написан на Go без фреймворков:
только стандартная библиотека и драйвер pgx для PostgreSQL.
Проект представляет собой REST API, который принимает и возвращает JSON.

## Что умеет

- регистрация и вход пользователей, авторизация по JWT
- расходы: добавление, просмотр своих записей, удаление
- категории трат с лимитами в процентах от бюджета
- статистика: общая сумма, количество операций, разбивка по категориям
- рекомендации: сравнение фактических трат с установленными лимитами

## Стек

- Go, стандартная библиотека net/http
- PostgreSQL, драйвер pgx
- JWT для авторизации
- bcrypt для хеширования паролей

## Запуск локально

1. Создайте базу данных PostgreSQL, например student_finance.
2. Создайте файл .env в корне проекта с одной переменной:

    JWT_SECRET=любая строка длиной от 32 символов

3. В internal/database/database.go укажите подключение к своей базе:
   пользователь, пароль, имя базы.
4. Запустите сервер:

    go run cmd/api/main.go

При первом запуске таблицы users, transactions и categories создаются
автоматически. Сервер слушает порт 7777, порт зашит в main.go —
при необходимости поменяйте там.

## Структура проекта

    cmd/api/main.go        точка входа, регистрация маршрутов
    internal/
      handlers/            HTTP-обработчики
        auth.go            регистрация и вход
        transaction.go     транзакции, статистика, рекомендации
        category.go        категории с лимитами
      auth/                хеширование паролей, выпуск и проверка JWT
      database/            подключение к БД и создание таблиц
      models/              структуры данных

## API

Все эндпоинты, кроме /api/register и /api/login, ожидают заголовок:

    Authorization: Bearer <token>

### Авторизация

POST /api/register — создать пользователя.
Запрос:

    {"username": "alina", "password": "123456"}

POST /api/login — войти, возвращает JWT-токен.
Запрос:

    {"username": "alina", "password": "123456"}

### Транзакции

POST /api/transactions — добавить трату.
Запрос:

    {
      "amount": 350,
      "category": "еда",
      "description": "обед"
    }

Поле date необязательное: если его не передать, подставится текущая дата.

GET /api/transactions — список транзакций текущего пользователя,
свежие записи первыми.

DELETE /api/transactions/{id} — удалить свою транзакцию.
Если id не существует или принадлежит другому пользователю, вернётся 404.

### Категории

POST /api/categories — создать категорию с лимитом бюджета.
Запрос:

    {"name": "еда", "percentage": 40}

Сумма процентов по всем категориям пользователя не должна превышать 100,
сервер проверяет это при создании.

GET /api/categories — список категорий текущего пользователя.

DELETE /api/categories/{id} — удалить свою категорию.

### Аналитика

GET /api/stats — итоги за всё время.
Ответ:

    {
      "total_amount": 1050,
      "transaction_count": 3,
      "by_category": {
        "еда": 850,
        "транспорт": 200
      }
    }

GET /api/recommendations — сравнение фактических трат с лимитами категорий.
Для каждой категории сервер считает, сколько потрачено и сколько было
можно в рамках лимита, и возвращает сообщение: warning при превышении,
success при экономии, info если трат по категории ещё не было.

Пример ответа:

    {
      "total_amount": 1000,
      "recommendations": [
        {
          "type": "warning",
          "message": "Категория 'еда': вы потратили 700 руб. (лимит 400 руб.). Превышение на 300 руб.! Попробуйте сократить расходы."
        }
      ]
    }

## Как устроена безопасность

- Пароли хранятся только в виде bcrypt-хешей, не в открытом виде.
- Токен подписан секретом из .env, сам файл добавлен в .gitignore
  и в репозиторий не попадает.
- id пользователя берётся из токена, а не из тела запроса,
  поэтому подставить чужой id невозможно.
- Все запросы к транзакциям и категориям фильтруются по user_id:
  один пользователь не видит и не может удалить данные другого.

## Быстрая проверка через curl

Регистрация:

    curl -X POST localhost:7777/api/register -H "Content-Type: application/json" -d '{"username":"alina","password":"123456"}'

Вход и получение токена:

    curl -X POST localhost:7777/api/login -H "Content-Type: application/json" -d '{"username":"alina","password":"123456"}'

Добавление траты:

    curl -X POST localhost:7777/api/transactions -H "Authorization: Bearer TOKEN" -H "Content-Type: application/json" -d '{"amount":350,"category":"еда"}'

Просмотр статистики:

    curl localhost:7777/api/stats -H "Authorization: Bearer TOKEN"
