# Student Finance

Персональный финансовый трекер. Позволяет отслеживать расходы, устанавливать лимиты по категориям и получать базовую аналитику трат.

---

## Технологии

- **Go** — бэкенд (стандартная библиотека `net/http`)
- **PostgreSQL** — база данных (драйвер `pgx`)
- **JWT** — аутентификация и авторизация
- **bcrypt** — хеширование паролей
